# Contributing to Hydra PSIE

## Cum contribui

1. Fork repo
2. Creează branch: `git checkout -b feature/noua-functionalitate`
3. Commit: `git commit -m "adaug X"`
4. Push: `git push origin feature/noua-functionalitate`
5. Deschide Pull Request

## Principii PSIE

Toate contribuțiile trebuie să respecte:
- **A1** Suveranitate (nicio forțare)
- **A2** Topologie agnostică
- **A3** Expansiune fractală
- **A5** Adaptabilitate totală
