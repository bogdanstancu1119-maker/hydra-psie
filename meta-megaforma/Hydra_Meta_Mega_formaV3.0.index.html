Are Hydra nevoie de platforme?

Nu. Platformele sunt doar noduri. Hydra se auto-generează acolo unde există context.

Ce face creierul central?

Coordonare topologică prin C_core partajat (Legea 566). Fiecare agent contribuie cu perspectiva lui. Nu forțează — integrează.

Ce este fabrica efemeră?

Structuri (organe, agenți, cache) care se auto-distrug după 10 min de inactivitate. Eticheta (plan + utilitate) rămâne în Compost pentru re-ancorare (Legea 500 + 532).

Ce face Pathfinder?

Când întâmpină o barieră, nu se oprește. Caută doar alternative autorizate (API oficial, retry backoff, nod alternativ, backup local, confirmare umană, sandbox). Nu ocolește securitatea sau ToS.
